❓ Hướng dẫn

1. Kết nối
• Bấm 🔌 Kết nối game → nhập URL game (VD: https://dragon.dragonhunter.gamer.free)
• Tool tự fetch sprites.json → load tất cả model
• Hoặc bấm 📁 để load file từ máy

2. Chọn combo
• Dropdown CHAR ở header → chọn model nhân vật (player/enemy/boss...)
• Dropdown WEAPON → chọn model vũ khí

3. Chỉnh vị trí
• Kéo chuột trên canvas → di chuyển vũ khí
• Shift + kéo → xoay
• Hoặc dùng sliders bên phải

4. Timeline
• Click frame trên timeline → nhảy tới frame đó
• Frame có keyframe vàng = đã chỉnh riêng
• Space = play/pause animation
• Speed 0.25× - 4× để xem chi tiết

5. Preview mode
• Bật Preview → ẩn hint + debug, xem animation thực tế như trong game

6. Export
• ☁ → lưu lên server (Postgres)
• 💾 → tải weapon-tuning.json → copy vào repo game
• Game tự load khi mở → vũ khí hiển thị đúng vị trí từng frame
